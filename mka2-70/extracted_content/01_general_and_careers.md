## 💼 2. 6 สายอาชีพเป้าหมายหลังสำเร็จการศึกษา (Target Careers)

หลักสูตร 2570 ได้ปรับเปลี่ยนกลุ่มอาชีพเป้าหมายให้ตรงกับความต้องการของตลาดแรงงานยุคดิจิทัลและ AI โดยระบุ 6 อาชีพหลัก ดังนี้:

1. **นักพัฒนาซอฟต์แวร์ (Software Developer / Software Engineer)**
   ผู้พัฒนาโปรแกรมประยุกต์ ทั้งบนเว็บ (Web Application), อุปกรณ์เคลื่อนที่ (Mobile Application), และระบบงานองค์กร (Enterprise Systems)
2. **วิศวกรปัญญาประดิษฐ์ (Artificial Intelligence Engineer)** *(อาชีพใหม่ตามเกณฑ์ 2570)*
   ผู้ออกแบบ สร้าง และปรับแต่งโมเดลการเรียนรู้ของเครื่อง (Machine Learning), โมเดลภาษาขนาดใหญ่ (LLMs / Generative AI) และการประยุกต์ใช้ AI ในภาคธุรกิจ
3. **ผู้บริหารโครงการซอฟต์แวร์ (Software Project Manager / Scrum Master)**
   ผู้วางแผน ประสานงาน และบริหารจัดการทีมพัฒนาซอฟต์แวร์ให้สามารถส่งมอบงานได้ตรงตามเวลา คุณภาพ และงบประมาณ
4. **นักวิเคราะห์ระบบ (System Analyst / Solution Architect)**
   ผู้รวบรวมและวิเคราะห์ความต้องการของผู้ใช้ (Requirements Engineering) พร้อมออกแบบสถาปัตยกรรมระบบสารสนเทศให้ปลอดภัยและมีประสิทธิภาพ
5. **ผู้ดูแลระบบเครือข่ายและคลาวด์ (Network & Cloud Infrastructure Administrator / DevOps)**
   ผู้บริหารจัดการระบบเครือข่ายคอมพิวเตอร์ โครงสร้างพื้นฐานบนคลาวด์ ความมั่นคงปลอดภัยไซเบอร์ (Cybersecurity) และระบบส่งมอบซอฟต์แวร์แบบอัตโนมัติ
6. **นักวิชาการคอมพิวเตอร์ (Computer Technical Officer / IT Support Specialist)**
   บุคลากรสายวิชาชีพคอมพิวเตอร์ในหน่วยงานภาครัฐ สถาบันการศึกษา และองค์กรธุรกิจที่รับผิดชอบระบบสารสนเทศโดยรวม

## 🎯 3. ตารางความสัมพันธ์ระหว่างอาชีพกับทักษะของบัณฑิต (Skill Mapping Matrix)

| อาชีพ / ตำแหน่งงาน | ทักษะทั่วไป (General Skills) | ทักษะเฉพาะทางวิชาชีพ (Specific Technical Skills) |
| :--- | :--- | :--- |
| **นักพัฒนาซอฟต์แวร์**<br>*(Software Developer)* | • การคิดและแก้ปัญหาเชิงตรรกะ (Logical Thinking)<br>• การสื่อสารและการนำเสนอผลงาน<br>• ทักษะการเรียนรู้เทคโนโลยีใหม่ด้วยตนเอง | • การเขียนโปรแกรม (Python, Java, JavaScript/TypeScript, PHP)<br>• การออกแบบและจัดการฐานข้อมูล (SQL & NoSQL)<br>• การพัฒนา Full-Stack Web & Mobile Application<br>• การใช้งาน Git Version Control และ RESTful APIs |
| **วิศวกรปัญญาประดิษฐ์**<br>*(AI Engineer)* | • การคิดเชิงวิเคราะห์และการตั้งสมมติฐาน<br>• การแก้ปัญหาเชิงคำนวณที่ซับซ้อน<br>• จริยธรรมในการใช้งานปัญญาประดิษฐ์ | • พื้นฐานคณิตศาสตร์ สถิติ และการวิเคราะห์เชิงตัวเลข<br>• การพัฒนาโมเดล Machine Learning & Deep Learning<br>• การจัดการและวิเคราะห์ข้อมูลขนาดใหญ่ (Big Data Analytics)<br>• การประยุกต์ใช้ Generative AI ในการพัฒนาซอฟต์แวร์ |
| **ผู้บริหารโครงการซอฟต์แวร์**<br>*(Software Project Manager)* | • ทักษะความเป็นผู้นำและการทำงานเป็นทีม<br>• การบริหารเวลาและการจัดลำดับความสำคัญ<br>• การเจรจาต่อรองและการสื่อสารข้ามสายงาน | • การบริหารโครงการซอฟต์แวร์ด้วย Agile / Scrum Framework<br>• การประเมินความเสี่ยงและทรัพยากรของโครงการ<br>• การติดตามและประกันคุณภาพซอฟต์แวร์ (QA & Testing) |
| **นักวิเคราะห์ระบบ**<br>*(System Analyst)* | • การวิเคราะห์ปัญหาและการคิดเชิงระบบ<br>• การสื่อสารและการสัมภาษณ์ผู้ใช้งาน<br>• การจัดการความขัดแย้งในโครงการ | • การวิเคราะห์และออกแบบระบบ (UML & System Architecture)<br>• การจัดทำเอกสารข้อกำหนดความต้องการ (Requirement Specification)<br>• การออกแบบประสบการณ์และส่วนต่อประสานผู้ใช้ (UX/UI Design)<br>• การออกแบบความปลอดภัยของระบบสารสนเทศ |
| **ผู้ดูแลระบบเครือข่าย**<br>*(Network Administrator)* | • การแก้ปัญหาเฉพาะหน้าภายใต้ภาวะวิกฤต<br>• การสื่อสารเพื่อช่วยเหลือผู้ใช้งาน (Helpdesk Skills)<br>• ความละเอียดรอบคอบในการรักษาความปลอดภัย | • การติดตั้ง กำหนดค่า และบริหารเครือข่าย (Routing, Switching, VLAN)<br>• การบริหารเซิร์ฟเวอร์ Linux และ Windows Server<br>• การบริหารคลาวด์และการใช้งาน Container (Docker/Kubernetes)<br>• การป้องกันและตรวจจับภัยคุกคามทางไซเบอร์ (Cybersecurity) |
| **นักวิชาการคอมพิวเตอร์**<br>*(Computer Technical Officer)* | • การถ่ายทอดความรู้ทางเทคนิคให้เข้าใจง่าย<br>• การบริการด้วยใจ (Service Mind)<br>• มารยาทและจรรยาบรรณวิชาชีพไอที | • การดูแลบำรุงรักษาฮาร์ดแวร์ ซอฟต์แวร์ และระบบเครือข่าย<br>• การพัฒนาและดูแลเว็บไซต์/เว็บแอปพลิเคชันของหน่วยงาน<br>• การบริหารฐานข้อมูลและการสำรองข้อมูลระบบ<br>• การประยุกต์ใช้เครื่องมือดิจิทัลและ AI ช่วยสนับสนุนงานองค์กร |
