## 👥 1. กลุ่มผู้มีส่วนได้เสียและวิธีการเก็บข้อมูล (Stakeholder Groups)

หลักสูตรวิทยาการคอมพิวเตอร์ (พ.ศ. 2570) ได้สำรวจและรวบรวมความต้องการจากผู้มีส่วนได้เสียทั้งภายในและภายนอกอย่างครอบคลุม เพื่อนำมากำหนดผลลัพธ์การเรียนรู้ (PLOs):

| กลุ่มผู้มีส่วนได้เสีย / ข้อกำหนด | วิธีการเก็บรวบรวมข้อมูล | กลุ่มเป้าหมายสำคัญ |
| :--- | :--- | :--- |
| **นโยบายกระทรวง อว.** | Documentary Review | นโยบายการศึกษา Outcome-Based Education (OBE) และการผลิตกำลังคนดิจิทัล (S-Curve) |
| **นโยบายสภามหาวิทยาลัย / มหาวิทยาลัย** | Documentary Review | แผนยุทธศาสตร์มหาวิทยาลัยราชภัฏเพื่อการพัฒนาท้องถิ่นอย่างยั่งยืน |
| **ผู้ใช้บัณฑิต (Employers)** | การสัมภาษณ์เชิงลึก (In-depth Interview) | สมาคมโปรแกรมเมอร์ไทย, สวทช., และสถานประกอบการซอฟต์แวร์เอกชน |
| **ศิษย์เก่า (Alumni)** | การสัมภาษณ์เชิงลึก และแบบสำรวจ | บัณฑิตที่ทำงานในตำแหน่ง Developer, DevOps, Data Analyst, IT Support |
| **ผู้เรียนในอนาคต (Prospective Students)** | การสัมภาษณ์เชิงลึก และแบบสอบถาม | นักเรียน ม.6 และ ปวช. สายช่างและคอมพิวเตอร์ |
| **ผู้บริหาร คณาจารย์ และนักศึกษาปัจจุบัน** | การสัมภาษณ์เชิงลึก และการประชุมกลุ่มย่อย | ตัวแทนนักศึกษาทุกชั้นปี และคณาจารย์ประจำหลักสูตร |

## 📊 2. สรุปความต้องการและการแปลงสู่ผลลัพธ์การเรียนรู้ (Needs-to-PLOs Mapping)

| ผู้มีส่วนได้เสีย (Stakeholders) | สรุปความต้องการและข้อกำหนด (Needs & Requirements) | ผลลัพธ์การเรียนรู้ที่สอดคล้อง |
| :--- | :--- | :---: |
| **กระทรวง อว.** | เน้นการจัดการศึกษาแบบ OBE และสมรรถนะกำลังคนด้านดิจิทัลระดับสูง | **PLO6, PLO7** |
| **สภามหาวิทยาลัย / มหาวิทยาลัย** | มุ่งเน้นการแก้ปัญหาและสร้างนวัตกรรมเพื่อยกระดับคุณภาพชีวิตของชุมชนท้องถิ่น | **PLO8** |
| **คณะวิทยาศาสตร์และเทคโนโลยี** | การสร้างความรู้สู่ชุมชน และการผลิตบัณฑิตที่มีคุณธรรม จริยธรรม และกฎหมายไอที | **PLO8, PLO10** |
| **อัตลักษณ์วไลยอลงกรณ์** | "บัณฑิตอาสา" มีวินัย ใฝ่รู้ สื่อสารได้ดี และทำงานเป็นทีมได้ราบรื่น | **PLO1, PLO9, PLO10** |
| **ผู้ใช้บัณฑิต (Employers)** | ต้องการบัณฑิตที่มีทักษะ **Coding, Cybersecurity, Cloud, System Analysis** สามารถเขียนโค้ดได้จริง และเข้าใจมาตรฐานอุตสาหกรรมซอฟต์แวร์ | **PLO6, PLO7** |
| **ศิษย์เก่า (Alumni)** | ต้องการให้หลักสูตรสอนทักษะการแก้ปัญหาหน้างาน การใช้เครื่องมือสมัยใหม่ (Git, Framework, Docker) และทักษะการเรียนรู้ด้วยตนเอง | **PLO7, PLO10** |
| **ผู้เรียนในอนาคต (Students)** | ต้องการเรียนรู้เทคโนโลยี AI, การพัฒนาเว็บและโมบายล์แอปพลิเคชัน และมีโอกาสฝึกงานกับบริษัทชั้นนำ | **PLO6, PLO7, PLO8** |

## 🎯 3. สาระสำคัญสำหรับนำไปใช้บนเว็บไซต์ (Web & PR Value)
