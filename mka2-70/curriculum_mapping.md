# 📋 ตารางวิเคราะห์ความสอดคล้องของผลลัพธ์การเรียนรู้เฉพาะทางวิชาชีพ (KSEC Alignment Matrix - PLO6–10)

## 5. ตารางแผนการพัฒนาสมรรถนะและการประเมินผลลัพธ์การเรียนรู้รายชั้นปี (Yearly PLO Progression & Assessment Map)

ตารางแสดงการจัดสรรระดับสมรรถนะเป้าหมายเฉพาะทางวิชาชีพ (PLO6–PLO10) จำแนกตามระดับชั้นปีที่พัฒนาหลัก และกระบวนการประเมินผลลัพธ์การเรียนรู้ (Assessment Methods):

| PLOs | ชั้นปีที่ 1 | ชั้นปีที่ 2 | ชั้นปีที่ 3 | ชั้นปีที่ 4 |
| :--- | :--- | :--- | :--- | :--- |
| **PLO6** (ทฤษฎีและการแก้ปัญหา) | เข้าใจโครงสร้างข้อมูล อัลกอริทึม ตรรกศาสตร์ดิจิทัล และทักษะการเขียนโปรแกรมเบื้องต้น | | | |
| **PLO7** (วิศวกรรมระบบและซอฟต์แวร์) | | วิเคราะห์และออกแบบระบบ คอมพิวเตอร์เครือข่ายและความปลอดภัย รวบรวมความต้องการ และออกแบบ UI/UX | | |
| **PLO8** (นวัตกรรมเพื่อท้องถิ่น) | | | จัดการนวัตกรรมและธุรกิจดิจิทัล พัฒนาตัวแบบนวัตกรรมต้นแบบ (Prototype) เพื่อแก้ปัญหาจริงของท้องถิ่น | |
| **PLO9** (การสื่อสารและการทำงานทีม) | | | | สื่อสารและเขียนรายงานเชิงเทคนิค ทำการนำเสนอ/เจรจาต่อรอง บริหารจัดการทีม และแปลงเรื่องยากให้เข้าใจง่าย |
| **PLO10** (จริยธรรมและการเรียนรู้ตลอดชีวิต) | | | | ปฏิบัติตามจรรยาบรรณวิชาชีพไอที ตระหนักถึงกฎหมายคอมพิวเตอร์และ PDPA พร้อมปรับตัวเรียนรู้เทคโนโลยีใหม่ๆ (AI, Cloud) |
