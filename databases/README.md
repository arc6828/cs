# คู่มือและข้อกำหนดฐานข้อมูลผลงานตีพิมพ์ (Publications Database Documentation)

เอกสารนี้บันทึกข้อตกลง โครงสร้างข้อมูล และแนวทางปฏิบัติสำหรับการจัดเก็บและบริหารจัดการข้อมูลผลงานทางวิชาการและงานวิจัยของหลักสูตรวิทยาการคอมพิวเตอร์

---

## 📌 1. โครงสร้างรหัสประจำผลงาน (Publication ID Scheme)

* **รูปแบบที่ใช้ในปัจจุบัน:** **`PUB-NNN`** (Prefix `PUB-` ตามด้วยตัวเลข Running 3 หลัก)
  * ตัวอย่าง: `PUB-001`, `PUB-002`, ..., `PUB-093`
* **ทิศทางการรันเลข (Numbering Sequence):**
  * รันตามลำดับเวลาจาก **อดีตมาปัจจุบัน (เก่าสุด ➔ ใหม่สุด)**
  * ผลงานชิ้นแรกในอดีต (ปี 2018) เริ่มต้นที่ `PUB-001`
  * ผลงานล่าสุดปัจจุบัน (ปี 2026) อยู่ที่ `PUB-093`
  * **ผลงานใหม่ที่เพิ่มเข้ามาในอนาคต:** ให้รันเลขต่อท้ายเป็น `PUB-094`, `PUB-095`, `PUB-096` ไปเรื่อย ๆ

---

## ⚠️ 2. นโยบายเมื่อมีการลบข้อมูล (Deletion & Gap Policy)

* **ห้ามรันเลขใหม่เพื่อถมช่องว่าง (Immutable ID):**
  * รหัส ID มีสถานะเป็นตัวตนถาวร (Unique Identifier) 
  * หากมีการลบผลงานชิ้นใดออกไป (เช่น ลบ `PUB-050`) **ให้ปล่อยให้รหัสนั้นว่าง (Gap) ไปเลย ห้ามเลื่อนรหัสชิ้นอื่นมาแทนที่เด็ดขาด**
  * เพื่อป้องกันปัญหา Broken Links, การอ้างอิงผิดพลาด และความเสียหายต่อความสัมพันธ์ของข้อมูลกับอาจารย์ (`teacher_ids`)
* **การแสดงผลบนหน้าเว็บไซต์:**
  * หน้าเว็บใช้ตัวนับแถว (Display Row Index: 1, 2, 3...) แยกขาดจากรหัส `id`
  * ดังนั้น ต่อให้ ID มีการแหว่ง ลำดับที่แสดงบนตารางและหน้ารวมผลงานจะยังคงเรียงลำดับ 1, 2, 3 สวยงามตามปกติ 100%

---

## 🔮 3. แนวทางพิจารณาในอนาคต (Future Roadmap)

* หากในอนาคตปริมาณข้อมูลเพิ่มขึ้นมาก หรือต้องการให้รหัสสื่อปีที่เผยแพร่อย่างชัดเจน สามารถพิจารณาปรับใช้รูปแบบ:
  * **`PUB-YYYY-NN`** (เช่น `PUB-2026-01`, `PUB-2026-02`, `PUB-2027-01`)
  * ซึ่งจะรีเซ็ตนับ `01` ใหม่ในแต่ละปี ค้นหาและจัดการรายปีได้สะดวกรวดเร็ว

---

## 📚 4. มาตรฐานการกำหนดค่า Tier ของวารสาร (Journal Tier Standard)

ฟิลด์ `"tier"` ในข้อมูลบทความวารสาร (`"type": "journal"`) กำหนดมาตรฐานค่าไว้ดังนี้:
1. **`TCI 1`:** วารสารระดับชาติที่ผ่านการรับรองคุณภาพในฐานข้อมูล TCI กลุ่มที่ 1 (เช่น วารสารวิจัยและพัฒนา วไลยอลงกรณ์ฯ, วารสารบัณฑิตศึกษา มรภ.วไลยอลงกรณ์ฯ, วารสารวิทยาศาสตร์ฯ ม.มหาสารคาม)
2. **`TCI 2`:** วารสารระดับชาติที่ผ่านการรับรองคุณภาพในฐานข้อมูล TCI กลุ่มที่ 2 (เช่น วารสารวิทยาศาสตร์ฯ มรภ.อุดรธานี, วารสารวิจัยและนวัตกรรมทางศึกษา, วารสารพัฒนาการเรียนการสอน ม.รังสิต, Advance Science Journal)
3. **`เกณฑ์ กพอ.`:** วารสารวิชาการที่จัดทำตามเกณฑ์มาตรฐาน ก.พ.อ. (ผู้ทรงคุณวุฒิประเมิน 3 ท่านแบบ Double-blind) เช่น วารสารวิจัยและนวัตกรรมทางวิทยาศาสตร์และเทคโนโลยี (JRIST) ของคณะวิทยาศาสตร์ฯ วไลยอลงกรณ์ฯ
4. **`Scopus Q1` - `Scopus Q4`:** วารสารระดับนานาชาติที่จัดอยู่ในฐานข้อมูล Scopus / SCImago Journal Rank (เช่น Information MDPI ➔ Scopus Q2, ICIC Express Letters ➔ Scopus Q4)

---

## 📖 5. ฐานข้อมูลอ้างอิงวารสารหลัก (Master Journal Database: `journals.json`)

เพื่อป้องกันความผิดพลาดและลดความซ้ำซ้อนในการบันทึกข้อมูล ได้จัดทำฐานข้อมูลอ้างอิงวารสารไว้ที่:
* `databases/journals.json` (และ mirrored ที่ `json/journals.json`)

### โครงสร้างข้อมูลวารสาร (Journal Schema พร้อมประวัติการปรับฐาน):
```json
{
  "id": "JRN-002",
  "name_th": "วารสารวิจัยและพัฒนา วไลยอลงกรณ์ ในพระบรมราชูปถัมภ์ (สาขาวิทยาศาสตร์และเทคโนโลยี)",
  "name_en": "VRU Research and Development Journal Science and Technology",
  "abbr": "VRDJ-Sci",
  "category": "วารสารระดับชาติ",
  "tier": "TCI 1",
  "current_tier": "TCI 1",
  "tier_history": [
    {
      "round": "TCI รอบที่ 5 (พ.ศ. 2568 - 2572)",
      "tier": "TCI 1",
      "period": "2025 - 2029",
      "status": "active"
    },
    {
      "round": "TCI รอบที่ 4 (พ.ศ. 2563 - 2567)",
      "tier": "TCI 1",
      "period": "2020 - 2024",
      "status": "historical"
    },
    {
      "round": "TCI รอบที่ 3 (พ.ศ. 2558 - 2562)",
      "tier": "TCI 1",
      "period": "2015 - 2019",
      "status": "historical"
    }
  ],
  "indexing": ["TCI 1", "ThaiJO"],
  "publisher": "สถาบันวิจัยและพัฒนา มหาวิทยาลัยราชภัฏวไลยอลงกรณ์ ในพระบรมราชูปถัมภ์",
  "issn_print": "2651-1274",
  "issn_online": "2651-1282",
  "peer_review_type": "Double-blind (3 Reviewers)",
  "frequency": "3 ฉบับ/ปี",
  "url": "https://ph01.tci-thaijo.org/index.php/vrdj_sci"
}
```

### ประโยชน์ในการใช้งาน:
1. **Single Source of Truth:** เมื่อ TCI หรือ Scopus ประกาศผลรอบใหม่ อัปเดต `current_tier` และเพิ่มประวัติลงใน `tier_history` ที่เดียว
2. **Snapshot vs History:** ในบทความ (`publications.json`) ล็อกค่า Tier ณ ปีที่ตีพิมพ์ไว้ถาวร ส่วนในวารสาร (`journals.json`) เก็บทั้งฐานปัจจุบันและประวัติย้อนหลัง ทำให้ตอบโจทย์ทั้งการส่งบทความใหม่ และการตรวจประเมินประกันคุณภาพ/ขอกำหนดตำแหน่งทางวิชาการ
3. **Auto-fill / Lookup:** ในอนาคตเมื่อเพิ่มผลงานใหม่ เพียงระบุ `journal_id` หรือเลือกชื่อวารสาร ระบบสามารถดึงข้อมูล Tier, ผู้จัดพิมพ์, ISSN, ลิงก์ TCI มาแสดงผลได้ทันทีโดยไม่ต้องพิมพ์ซ้ำ
4. **Data Consistency:** หมดปัญหาการสะกดชื่อวารสารผิด หรือเขียนชื่อย่อไม่ตรงกันในแต่ละผลงาน
